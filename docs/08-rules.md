# 08. Правила работы над проектом

Актуально на 16.09.2026. Правила выведены из конкретных проблем, уже
случившихся в проекте — у каждого раздела есть цена, которую за него уже
заплатили.

---

## 1. Единый источник истины

| Что | Источник истины | Никогда не источник |
|---|---|---|
| Поведение прибора | Прошивка **STM32L072CBT6** | Память, документация, GD32 |
| Конфигурация периферии ST | Файл `.ioc` | Сгенерированный `Core/` |
| Распиновка | `Core/Inc/main.h` | Комментарии в коде |
| Версии инструментов | `tools/manifest.json` | То, что стоит на машине |
| Состояние проекта | Эта документация | Переписка и память |

**L072 — эталон.** При любом расхождении «как должно работать» ответ ищется
в нём. Пока L072 не собран и не проверен, сравнивать GD32 и L071 не с чем.

## 2. Работа с CubeMX

**Цена нарушения:** потерянная конфигурация АЦП в L071 — прошивка
собиралась, но показывала 0 °C. См. П-02 и П-03 в
[07-troubleshooting.md](07-troubleshooting.md).

1. **Настройки периферии меняются только через `.ioc`.** Правка
   сгенерированного кода поверх — запрещена: она исчезнет при следующей
   генерации, молча.
2. Если нужного параметра в CubeMX нет — правка идёт **внутрь блока**
   `/* USER CODE BEGIN ... */ ... /* USER CODE END ... */`.
3. **Перед перегенерацией** — зафиксировать текущее состояние в git, чтобы
   потерю было видно в диффе.
4. **После перегенерации** — обязательный дифф `Core/`:

   ```bash
   git diff --stat -- '*/Core/'
   ```

   Просмотреть каждое удаление. Исчезнувшая строка `HAL_ADC_ConfigChannel`
   стоила проекту месяцев.
5. `.ioc` и сгенерированный код обязаны совпадать. Известное расхождение
   (`SamplingTime` в L072) — подлежит устранению, а не копированию.

## 3. Тулчейн

**Цена нарушения:** оба ST-проекта не собираются после переустановки MDK.

1. Версии компилятора, MDK и пакетов поддержки устройств **зафиксированы**
   в `tools/manifest.json`. Обновление версии — отдельное решение с записью
   в [adr/](adr/), а не побочный эффект переустановки.
2. Настройка компилятора в `.uvprojx` (`<uAC6>`) не меняется произвольно.
   Смена компилятора — отдельная задача, **не совмещаемая** с правкой логики
   или конфигурации.
3. Перед установкой нового инструмента — пополнить офлайн-комплект и
   манифест. Инструмент, которого нет в `tools/`, считается недоступным.
4. После развёртывания окружения — прогнать проверку из
   [03-environment.md](03-environment.md): сборка L072 должна дать
   **ROM 27.14 КБ**.

## 4. Общая кодовая база

**Цена нарушения:** правка в трёх копиях и расхождения, всплывающие на железе.

1. **В `app/` нет вызовов HAL и SPL.** Проверяется автоматически:

   ```bash
   grep -rnE "HAL_|gd32|GPIO[A-C]->|->(BSRR|IDR|ODR)" app/ && echo "НАРУШЕНИЕ"
   ```

2. Изменение поведения вносится **только в `app/`**. Если правка требуется
   в порте — значит, контракт неполон: сначала расширяется `ports.h`.
3. Новый параметр, зависящий от железа (частота, размер страницы, объём
   памяти), становится **параметром порта**, а не константой в логике.
4. Порт `stm32l0` общий для L071 и L072. Появление в нём условной
   компиляции по чипу — сигнал, что различие следует вынести в параметр.

## 5. Git

**Цена нарушения:** в индексе 47 артефактов сборки и 939 файлов вендоренных
драйверов; рабочее дерево 296 МБ.

1. **Артефакты сборки не коммитятся.** Сейчас в индексе лежат `.o`, `.axf`,
   `.htm`, `.dep` — подлежат удалению из индекса:

   ```bash
   git rm -r --cached keil/Objects keil/Listings
   ```

2. **Библиотеки производителя вендорятся намеренно** — это условие
   офлайн-сборки, и решение сознательное. Но копия должна быть **одна**:
   сейчас `Drivers/` продублирован в L071 и L072 по 67 МБ.
3. Ветка на задачу, имя по существу: `fix/l071-adc-config`,
   `feat/app-port-layer`, `docs/environment`.
4. Коммит — одно законченное изменение. Сообщение на русском, в
   повелительном наклонении, с указанием таргета, если он один:
   `L071: вернуть каналы TEMPSENSOR и VREFINT`.
5. **Не коммитить в рабочем состоянии «собралось, но не проверено».** Если
   проверка на железе не проводилась — сказать об этом в теле коммита.
6. Незакоммиченная работа не считается существующей. Сейчас вне git
   находится весь каталог `STM32L071CBT6/` — это подлежит исправлению
   первым же коммитом.

## 6. Документация

**Цена нарушения:** три попытки портирования без записи того, что уже
пробовали и почему не вышло.

1. **Документация — часть определения «готово».** Изменение, не отражённое
   в документации, считается незавершённым.
2. Обновляется в том же коммите, что и код. Не «потом».
3. Каждый документ несёт дату актуальности в начале.
4. Отрицательный результат документируется наравне с положительным: запись
   «ST-Link в режиме J-Link с GD32 не заработал» экономит следующему
   человеку неделю. Такие записи — в [07-troubleshooting.md](07-troubleshooting.md).
5. Решения с последствиями — в [adr/](adr/), по одному файлу: контекст,
   варианты, решение, последствия. ADR не редактируется задним числом —
   устаревший помечается статусом «заменено на ADR-NNNN».
6. `README.md` в корне репозитория содержит переписку по отладке АЦП
   (748 строк). Это черновик, а не документация: полезное из него переносится
   в [07-troubleshooting.md](07-troubleshooting.md), остальное удаляется.

## 7. Приёмка изменений

Изменение считается готовым, когда выполнено **всё**:

- [ ] Собирается без ошибок и предупреждений на всех затронутых таргетах.
- [ ] Размер прошивки сверен с эталоном (или новый эталон зафиксирован).
- [ ] Проверено **на железе** по чек-листу из
      [04-build-and-flash.md](04-build-and-flash.md).
- [ ] `app/` не содержит обращений к HAL и SPL (греп из раздела 4).
- [ ] `.ioc` и сгенерированный код совпадают.
- [ ] Документация обновлена в том же коммите.
- [ ] Артефакты сборки не попали в индекс.

Сборка без ошибок **не означает работоспособность**: L071 собирается в
корректную прошивку, которая не измеряет температуру.

---

## 8. Порядок ведения трёх таргетов

1. Новая функциональность сначала появляется на **эталонном L072**.
2. Затем переносится в `app/` и проверяется на L071.
3. GD32 подтягивается последним.
4. Расхождение между таргетами существует **только в `port/`**. Расхождение
   в `app/` — дефект.
5. Перед началом работ по новому ТЗ — свериться, не требует ли оно новой
   периферии. Расширить контракт заранее дешевле, чем переделывать три порта.
