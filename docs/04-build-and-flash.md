## Сборка из uVision

1. Открыть `.uvprojx`.
2. Убедиться, что выбран нужный таргет и компилятор:
   `Project → Options for Target → Target → ARM Compiler`.
3. `Project → Rebuild all target files` (F7).
4. Проверить в `Build Output`: должно быть `0 Error(s), 0 Warning(s)`.

## Сборка из командной строки

```bash
"C:\Keil_v5\UV4\UV4.exe" -j0 -b STM32L072CBT6\MDK-ARM\STM32L072CBT6.uvprojx \
    -o build_l072.log
```

Ключи: `-b` — сборка, `-j0` — без диалогов, `-o` — файл лога. UV4 всегда
возвращает код 0, поэтому **результат определяется по логу**, а не по коду
возврата:

```bash
grep -E "0 Error|Error\(s\)" build_l072.log
```

Сборка всех трёх таргетов одной командой появится после перехода на
CMake — см. [adr/0001-toolchain.md](adr/0001-toolchain.md).

## Эталонные размеры

Совпадение размера — основной критерий того, что собран тот же код тем же
компилятором с теми же ключами.

| Таргет | Code + RO Data | RW + ZI | ROM Total | Компилятор |
|---|---|---|---|---|
| STM32L072CBT6 | 27 640 (26.99 КБ) | 2 096 | **27 796 (27.14 КБ)** | armcc 5.06u7 |
| STM32L071CBT6 | 27 392 (26.75 КБ) | 2 056 | **27 544 (26.90 КБ)** | armcc 5.06u7 |
| GD32E103C8T6 | 7 948 (7.76 КБ) | 2 160 | 7 952 (7.77 КБ) | неполная прошивка |

Размеры берутся из `.map` в конце файла, раздел `Total ROM Size`.

> При смене компилятора на ArmClang или GCC эти числа изменятся. Тогда
> эталон фиксируется заново — функциональной проверкой на железе.

## Прошивка

### ST-таргеты (L071, L072)

Отладчик ST-Link, интерфейс SWD. Из uVision:
`Flash → Download` (F8). Либо внешней утилитой по `.hex`.

Задействованные линии отладки сохраняются: в GD32-варианте JTAG отключается
явно, SWD остаётся (`gpio_pin_remap_config(GPIO_SWJ_SWDPENABLE_REMAP, ENABLE)`).

### GD32E103C8T6

Официально поддерживается J-Link. Опыт проекта, зафиксированный в
`README.md` репозитория: попытка превратить китайский ST-Link в J-Link
**с GD32 не заработала** — подружить не удалось. Сама перепрошивка ST-Link
в J-Link удалась (сначала накатывается обычная прошивка STM32 + VCP), но
с GigaDevice связка не заработала. Рабочий путь — отдельный J-Link.

Артефакты прошлых попыток: `keil/JLinkLog.txt`, `keil/JLinkSettings.ini`.

## Проверка на железе

Сборка без ошибок не означает работоспособность — L071 собирается в
корректную прошивку, которая не измеряет температуру. Минимальная проверка
после прошивки:

1. **Дисплей** — при старте выводится приветствие и версия ПО бегущей строкой.
2. **Температура** — на экране `TEMP` показания отличны от нуля и правдоподобны.
   Ноль означает неработающий `VREFINT`, см. [07-troubleshooting.md](07-troubleshooting.md).
3. **Кнопки** — Menu переключает экраны, Left/Right меняют уставку.
4. **Уровень воды** — при срабатывании поплавка загорается индикатор «Капля»
   и прибор уходит в останов.
5. **Нагрев** — по Start включаются моторы и начинается нагрев; за 5 °C до
   уставки звучит сигнал готовности.

Пункты 1–2 обязательны: без них дальнейшая проверка бессмысленна.
