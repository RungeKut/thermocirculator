# Документация проекта «Термоциркулятор»

Прибор для термостатирования водяной ванны: поддержание заданной температуры
ТЭНом с ПИД-регулированием, принудительная циркуляция, контроль уровня воды,
управление с LCD1602 и пятикнопочной клавиатуры.

Прошивка существует для **трёх микроконтроллеров** — см. [01-overview.md](01-overview.md).
