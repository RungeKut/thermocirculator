# Офлайн-комплект для развёртывания окружения

Здесь собрано всё, что нужно, чтобы развернуть сборку проекта на машине
**без доступа в интернет**. Порядок установки — [../docs/03-environment.md](../docs/03-environment.md).

## Состав

```
tools/
├── README.md          этот файл
├── manifest.json      перечень: версии, размеры, sha256, источники
├── verify.py          проверка комплектности
├── installers/        крупные инсталляторы          (вне git)
├── packs/             пакеты поддержки устройств
└── datasheets/        документация на компоненты
```

## Проверка

```bash
python tools/verify.py
```

Код возврата 0 — комплект полон, 1 — не хватает обязательных позиций.
Скрипт печатает, чего нет, куда это положить и откуда взять.

В консоли Windows для корректного вывода кириллицы:

```
chcp 65001
```

## Пополнение комплекта

1. Положить файл по пути, который назвал `verify.py`.
2. Зафиксировать его размер и контрольную сумму в манифесте:

   ```bash
   python tools/verify.py --update
   ```

3. Закоммитить изменившийся `manifest.json` (сам файл в git не попадёт,
   если он крупный — см. ниже).

## Что под контролем версий, а что нет

В git попадают **манифест, скрипт проверки, пакеты и даташиты**. Крупные
инсталляторы исключены через `.gitignore` — иначе репозиторий вырастет на
гигабайт.

Это значит: **клон репозитория не даёт готовый комплект.** Для переноса
на другую машину каталог `tools/` копируется целиком, как есть, а манифест
позволяет убедиться, что он доехал без потерь.

## Текущее состояние

На 16.09.2026 в комплекте не хватает четырёх обязательных позиций:

| Чего нет | Зачем нужно |
|---|---|
| Arm Compiler 5.06u7 | **Без него не собирается ни один ST-проект** |
| Keil.STM32L0xx_DFP 2.2.0 | Поддержка STM32L071 и L072 в uVision |
| STM32CubeMX | Правка `.ioc`, восстановление конфигурации L071 |
| STM32Cube FW_L0 | Пакет прошивок для CubeMX в офлайне |

Их нужно один раз получить на машине с интернетом и добавить в комплект.
Arm Compiler 5 требует учётной записи Arm: он снят с поддержки и
распространяется как legacy-компонент.

## Версии зафиксированы

Пакеты поддержки устройств ставятся **строго тех версий**, что указаны в
манифесте — они прописаны в файлах проектов:

- `Keil.STM32L0xx_DFP.2.2.0` — в `.uvprojx` обоих ST-проектов;
- `GigaDevice.GD32E10x_DFP.1.3.0` — в `keil/gd32e103c8t6.uvprojx`.

Пакет `GigaDevice.GD32E10x_DFP.1.2.1` лежит в комплекте как историческая
версия и **для сборки не используется**.

Обновление любой версии — отдельное решение с записью в
[../docs/adr/](../docs/adr/), а не побочный эффект переустановки.
См. [правила работы](../docs/08-rules.md), раздел 3.

## Лицензирование

Лицензия на Keil MDK — на стороне владельца проекта. Лицензионные артефакты
в комплект намеренно не включены.

Для оценки вариантов: бесплатная редакция **MDK-Lite ограничена 32 КБ** кода,
а текущая прошивка занимает **27.14 КБ**. Формально помещается, но запас
около 5 КБ — расширение функций по новому ТЗ вероятно выведет её за лимит.
Это один из аргументов за переход на GCC, см.
[ADR-0001](../docs/adr/0001-toolchain.md).
