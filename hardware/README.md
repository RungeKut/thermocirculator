# Аппаратная часть: исходники плат

Перенесено в репозиторий 17.09.2026 из каталога `#05 Лазерная резка`, который
жил на рабочем столе. Оригинал может быть удалён — здесь полный комплект
исходников, достаточный, чтобы заказать платы заново.

Проект в Altium Designer. Открывать `AltiumWorkSpace.DsnWrk` — он подтягивает
оба проекта по относительным путям.

## Плата рассчитана на три процессора

**Это главное, что нужно знать про эту плату.** Она разрабатывалась так,
чтобы принимать pin-to-pin совместимые микроконтроллеры в LQFP48:

- **GD32E103C8T6** — установлен в перечне элементов (`DD2`), целевой для серии;
- **STM32L072CBT6** — исходный, на нём разработана эталонная прошивка;
- **STM32L071CBT6** — промежуточный.

Все три проверены пайкой на эту плату. Отсюда и три порта прошивки —
см. [ADR-0002](../docs/adr/0002-shared-codebase.md): слой `app/` + `port/`
это программное отражение того, что уже заложено в железо.

> При заказе стоит рассмотреть **GD32E103C**B**T6** вместо `C8T6`: тот же
> корпус и та же распиновка, но 128 КБ флеша вместо 64 и 32 КБ ОЗУ вместо 20.
> По оценке из [09-requirements.md](../docs/09-requirements.md) прошивка после
> переработки займёт ~42 КБ плюс 8 КБ хранилища — это 78 % от 64 КБ.

## Реальная плата отличается от схемы

В [`Вопросы - пожелания1.docx`](Вопросы%20-%20пожелания1.docx) есть раздел
«Замечания по первой версии платы СУ» — доработки, внесённые при отладке.
**Схема их не содержит.**

| Позиция | Доработка |
|---|---|
| R16 | заменён 33 кОм → **22 кОм** |
| VD4 | убран из схемы |
| RT2 | должен быть прямой характеристики, а не обратной — убран |
| VD7 | при 1 А греется до 70 °C, нужен радиатор или Шоттки с меньшим падением |
| VT1 | сток/исток поменять местами |
| T1 | не совпадают габариты футпринта; начало обмотки 2 не по даташиту |
| X1 | не совпадают габариты футпринта |
| C5 | велик по ёмкости и высоте, ограничить высотой L1 |
| Транзисторы на радиаторе | поднять на одно ребро вверх |

Перед повторным заказом плат этот список нужно внести в схему и разводку,
иначе ошибки первой версии повторятся.

## Узел обратной связи AC/DC

Источник питания: **220 В AC → 12 В DC, 1.3 А**, контроллер `DD1 TEA1733`.
Обратная связь изолированная, классическая:

```
+12V ──[R30 20 кОм]──┬── REF (D1 TL431ACDBZT)
                     │
                  [5,1 кОм]         катод TL431 ──> светодиод DA3 LTV-356T
                     │                                      │
                    GND                          на первичную сторону, FB TEA1733
```

Расчёт сходится: **2.495 × (1 + 20/5.1) = 12.28 В**.

> **Отсюда известный отказ.** Если не впаян **R30** (верхнее плечо делителя),
> вход REF у TL431 притянут к земле, TL431 не открывается, оптопара не
> светится, TEA1733 считает, что выход просел, и уходит на максимальную
> скважность. Напряжение на шине +12 В улетает вверх. Именно так был выведен
> из строя дисплей.
>
> После такого события проверять не только дисплей: `C14` и `C15` — это
> электролиты **на 16 В** на той же шине.

Нижнее плечо (5,1 кОм) при обрыве даёт безопасный отказ: выход просаживается.

## Что сюда не попало

Отброшено 233 МБ производного и постороннего — оставлено 38 файлов, 49.5 МБ:

- 3D-модели (`*.step`, `*.stp`, `*.SLDPRT`, `*.SLDASM`) — производное от плат;
- `Project Outputs for *`, `BackUp*.7z`, `КД/Altium.7z` — генерируемое и резервные копии;
- `Altium Library/` — библиотека общего назначения, не принадлежит проекту;
- `DataDheets/`, `DataSheets/` — даташиты, свободно доступны; нужные лежат в [`../tools/datasheets/`](../tools/datasheets/);
- `Пожелания от мастера.bmp` (25 МБ), дистрибутив GD-Link.

Если что-то из этого понадобится — оно в исходном каталоге у владельца проекта.

> Файлы `*.PcbDoc` занимают 40 МБ и почти не сжимаются: внутри уже сжатые
> потоки. Это плата за то, чтобы разводка не потерялась. Если плата начнёт
> активно меняться, правильный ответ — Git LFS.
