# Правила для ассистента в этом репозитории

Проект «Термоциркулятор» — прошивка прибора для термостатирования водяной
ванны, ведётся одновременно под **три микроконтроллера**.

Полная документация — в [docs/](docs/). Начинать с [docs/README.md](docs/README.md).

## Что нужно знать до первой правки

1. **Эталон — STM32L072CBT6.** Единственная полностью рабочая прошивка.
   При вопросе «как должно работать» ответ ищется там, а не в GD32 или L071.
2. **Окружение сейчас сломано.** Не собирается ни один таргет: отсутствует
   Arm Compiler 5 и не установлены пакеты поддержки устройств. Прежде чем
   диагностировать код — проверить [docs/07-troubleshooting.md](docs/07-troubleshooting.md), П-01.
3. **Сборка без ошибок не означает работоспособность.** L071 собирается в
   корректную прошивку, которая показывает 0 °C.

## Обязательные правила

Полный свод — [docs/08-rules.md](docs/08-rules.md). Кратко:

- Настройки периферии ST меняются **только через `.ioc`**. Правка
  сгенерированного `Core/` поверх — запрещена, она исчезнет молча.
- После любой перегенерации CubeMX — дифф `Core/` и просмотр **каждого
  удаления**. Исчезнувший `HAL_ADC_ConfigChannel` уже стоил проекту месяцев.
- Смена компилятора — отдельная задача, **не совмещаемая** с правкой логики
  или конфигурации.
- Версии инструментов зафиксированы в [tools/manifest.json](tools/manifest.json).
  Обновление — через [docs/adr/](docs/adr/), а не мимоходом.
- Артефакты сборки не коммитятся.
- Документация обновляется **в том же коммите**, что и код.

## После выделения общей кодовой базы

Когда появится каталог `app/` (см. [docs/06-porting.md](docs/06-porting.md)):

- **в `app/` не должно быть ни одного вызова HAL или SPL.** Проверка:

  ```bash
  grep -rnE "HAL_|gd32|GPIO[A-C]->|->(BSRR|IDR|ODR)" app/
  ```

- изменение поведения вносится только в `app/`;
- расхождение между таргетами допустимо только в `port/`.
